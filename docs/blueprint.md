# **App Name**: StarterSlate

## Core Features:

- Text Editor UI: Display a basic text editor interface with a text area.
- Formatting Tools: Provide standard formatting options (bold, italic, underline).
- Download Functionality: Allow users to download the current document.

## Style Guidelines:

- Primary color: A calming light blue (#A7D1FF) to promote focus.
- Background color: A very light grey (#F0F0F0) for a clean look.
- Accent color: A muted violet (#B2A2CC) for buttons and highlights, offering a subtle contrast.
- Font: 'Inter' sans-serif, for both body and headlines due to its neutral and modern appearance.
- Use minimalist, line-based icons for formatting options.
- A clean and simple layout with the text editor taking up most of the screen.
- Subtle transition animations when opening menus or dialogs.
